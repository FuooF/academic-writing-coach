# Sources and provenance

Reviewed: 22 October 2026.

Academic Writing Coach is independently maintained. Its workflow, revision rubric, 24 coaching cards, examples, and tools were written for this project. The example situations and measurements are illustrative, not published findings. The public repository does not contain a scraped phrase corpus, a translation of that corpus, or the saved web pages used in a user's local library.

## Project format and presentation

- The package follows the [Agent Skills format](https://agentskills.io/specification).
- The README arrangement was inspired by [Kiterlin/anti-defensive-writing](https://github.com/Kiterlin/anti-defensive-writing), as requested by the project initiator. The README prose and teaching examples here were written for this project; that repository is not a runtime dependency.
- The license text is the standard [MIT License](https://opensource.org/license/mit).

## User-local material

The optional importer reads a user-selected `content.json` exported from a local Phrasebank library. It preserves source URLs, page context, section identifiers, and relevant table structure in an external private data directory. Imported material is marked separately from original coaching cards and remains outside the project's MIT license.

Importing or reformatting a file does not grant permission to redistribute it. See [third-party notices](THIRD_PARTY_NOTICES.md) and [the publication guide](docs/PUBLISHING.md).
